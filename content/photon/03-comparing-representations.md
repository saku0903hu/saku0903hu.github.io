# 3. 異なる位置・運動量空間表現の比較 (Comparing different position and momentum space representations)

局所的に作用する消滅演算子 $a_{s\lambda}(x, t)$ の性質をさらに学ぶために、ハイゼンベルク描像における対応する量子化EM場の運動量空間表現をここで詳しく見る。そのために、ボソン交換関係を持つ粒子消滅演算子 $a_{s\lambda}(k, t)$ を導入する：

$$[a_{s\lambda}(k, t), a_{s'\lambda'}^\dagger(k', t)] = \delta_{s,s'} \delta_{\lambda,\lambda'} \delta(k - k') \tag{18}$$

古典電磁気学に着想を得て、また後で明らかになる理由により、以降では $a_{s\lambda}(x, t)$ と $a_{s\lambda}(k, t)$ の演算子が一般化フーリエ変換を介して関連していると仮定する：

$$a_{s\lambda}(x, t) = \int_{-\infty}^{\infty} dk \, f(k) \, e^{iskx} \, a_{s\lambda}(k, t) \tag{19}$$

この式の逆変換は以下を意味する：

$$a_{s\lambda}(k, t) = \frac{1}{2\pi} \int_{-\infty}^{\infty} dx \, f^{-1}(k) \, e^{-iskx} \, a_{s\lambda}(x, t) \tag{20}$$

ここで、任意の関数 $f(k)$ に対する逆変換は、正と負の周波数光子の両方が考慮される場合にのみ存在する。すなわち、パラメータ $k$ は $-\infty$ から $+\infty$ までの任意の値を取ることができる。

量子場の理論から、量子化EM場は $PT$ 変換のもとで不変であることが知られている。なぜなら、光は内部量子数を持たないからである [52]。例えば、自由空間では、正の $x$ 方向に進む直線偏光波束の電場振幅の記録と、同じ偏光で負の $x$ 方向に進む同形状の波束の電場振幅の記録を、後者を時間的に逆再生すれば区別できない [53–56]。これは電場観測量 $E(x, t)$ の式が $s$ と $t$ を同時に $-s$ と $-t$ に置き換える変換のもとで不変でなければならないことを示唆する。磁場観測量 $B(x, t)$ についても同様の議論ができる（式 (10) 参照）。

しかし、式 (8) の運動方程式からさらに強い結論が引き出せる：

$$x - sct = x - (-s)c(-t) \tag{21}$$

これら二つの式は、$a_{s\lambda}(x, t)$ 演算子のダイナミクスの生成子と $a_{-s\lambda}(x, -t)$ 演算子のダイナミクスの生成子が形式的に同一であることを意味する。両者は同じ固有値の集合を持つ。したがって、$s$ 方向に運動するすべての波束に対し、$-s$ 方向に運動し、時間を逆行させると全く同じように発展する別の波束が存在する。これは、量子化EM場の力学的ハミルトニアンが同量の正と負の固有値を持たなければならないことを意味する。また、力学的ハミルトニアン $H_\text{dyn}$ と量子化EM場のエネルギー観測量 $H_\text{eng}(t)$（式 (17)）は、後者が正の固有値のみを持つため、同一ではありえないことも意味する。

式 (8) の恒等式と式 (19) を組み合わせると、

$$a_{s\lambda}(x, t) = \int_{-\infty}^{\infty} dk \, f(k) \, e^{isk(x-sct)} \, a_{s\lambda}(k, 0) \tag{22}$$

量子光学から、このダイナミクスが調和振動子ハミルトニアンに対応することが分かる：

$$H_\text{dyn} = \sum_{s=\pm 1} \sum_{\lambda=H,V} \int_{-\infty}^{\infty} dk \, \hbar ck \, a_{s\lambda}^\dagger(k, 0) a_{s\lambda}(k, 0) \tag{23}$$

これは、シュレーディンガー描像における量子化EM場の状態 $|\psi_S(t)\rangle$ が確かにシュレーディンガー方程式に従って時間発展することを意味する：

$$i\hbar |\dot{\psi}_S(t)\rangle = H_\text{dyn} |\psi_S(t)\rangle \tag{24}$$

上記の力学的ハミルトニアン $H_\text{dyn}$ は $f(k)$ の任意の選択に対して適用され、自由空間におけるEM場の通常の調和振動子ハミルトニアン [26] とほぼ同一である。しかし、$H_\text{dyn}$ は正と負の固有値を持ち、もはや $H_\text{eng}(t)$ と一致しない。

次に、高度に局所化された場の励起の消滅演算子 $a_{s\lambda}(x, t)$ の交換関係を詳しく見る。例えば、式 (18) と (22) を組み合わせると、

$$[a_{s\lambda}(x, t), a_{s'\lambda'}^\dagger(x', t')] = \delta_{s,s'} \delta_{\lambda,\lambda'} \int_{-\infty}^{\infty} dk \, |f(k)|^2 \, e^{isk[x - sct - (x' - sct')]} \tag{25}$$

この交換関係は以下を意味する：

$$[\xi_{s\lambda}(x, t), \xi_{s'\lambda'}^\dagger(x', t')] = i\delta_{s,s'} \delta_{\lambda,\lambda'} \int_{-\infty}^{\infty} dk \, |f(k)|^2 \sin[sk(x - sct - (x' - sct'))] \tag{26}$$

当然ながら、$x - sct = x' - sct'$、$s = s'$、$\lambda = \lambda'$ の場合、$\xi_{s\lambda}(x, t)$ と $\xi_{s'\lambda'}(x', t')$ は同一であるため（式 (8) 参照）、この式はゼロとなる。

式 (22) を式 (17) に代入すると、エネルギー観測量 $H_\text{eng}(t)$ が運動量空間では以下に等しいことが分かる：

$$H_\text{eng}(t) = \sum_{s=\pm 1} \sum_{\lambda=H,V} \int_{-\infty}^{\infty} dk \, \pi\hbar c \left[ |f(k)|^2 a_{s\lambda}^\dagger(k,0) a_{s\lambda}(k,0) + \text{H.c.} + f(k) f(-k) a_{s\lambda}(k,0) a_{s\lambda}(-k,0) + \text{H.c.} \right] \tag{28}$$

これは時間に依存しない——当然そうあるべきである。この式の第二行の項の期待値は、正の $k$ のみまたは負の $k$ のみの光子状態が占有されている場合にゼロとなる。

次に、式 (28) のエネルギー観測量を調和振動子ハミルトニアンと異ならせる追加項を調べる。通常通り、真空状態 $|0\rangle$ はすべての光子消滅演算子 $a_{s\lambda}(k, t)$ の共有ゼロ固有状態である。これはゼロのエネルギーとゼロの電場・磁場期待値を持つEM場を記述する。式 (19) から分かるように、真空状態はすべての局所的に作用する消滅演算子 $a_{s\lambda}(x, t)$ によっても消滅される：

$$a_{s\lambda}(k, t)|0\rangle = a_{s\lambda}(x, t)|0\rangle = 0 \tag{29}$$

すべてのパラメータ $k$、$x$、$t$ に対して成り立つ。また、真空状態 $|0\rangle$ は、複素数 $\alpha_{s\lambda}(k)$ でパラメトライズされるコヒーレント状態 $|\alpha_{s\lambda}(k)\rangle$ の一例である：

$$a_{s\lambda}(k, 0)|\alpha_{s\lambda}(k)\rangle = \alpha_{s\lambda}(k)|\alpha_{s\lambda}(k)\rangle \tag{30}$$

式 (10) と (19) を考慮すると、同じ場の期待値 $\langle E(x, t)\rangle$ と $\langle B(x, t)\rangle$ を持つ異なるコヒーレント状態が存在することが示せる。例えば、実数の $f(k)$ の場合、$\alpha_{s\lambda}(-k) = \alpha_{s\lambda}(k)^*$ であるコヒーレント状態 $|\alpha_{s\lambda}(k)\rangle$ と $|\alpha_{s\lambda}(-k)\rangle$ に対してこれが当てはまる。両方のコヒーレント状態は同じ方向に伝搬する光を記述し、電場と磁場の期待値だけでは区別不可能である。したがって、$\alpha_{s\lambda}(-k) = \alpha_{s\lambda}(k)^*$ の形の状態 $|\alpha_{s\lambda}(k)\rangle|\alpha_{s\lambda}(-k)\rangle$ の電場・磁場振幅は建設的に干渉する。そのため、その全エネルギー $\langle H_\text{eng}(t)\rangle$ は $|\alpha_{s\lambda}(k)\rangle$ のエネルギーの4倍となる（式 (28) 参照）。同様に、$\alpha_{s\lambda}(-k) = -\alpha_{s\lambda}(k)^*$ の形の状態 $|\alpha_{s\lambda}(k)\rangle|\alpha_{s\lambda}(-k)\rangle$ は真空状態と同じエネルギー期待値 $\langle H_\text{eng}(t)\rangle = 0$ を持つことが示せる。これが、エネルギー観測量がもはや調和振動子ハミルトニアンと一致しない理由である。

## 3.1 高度に局所化された場の励起 (Highly localized field excitations)

上述のように、関数 $f(k)$ の物理的に整合する選択には多くの異なるものがあり、量子化EM場の異なる物理的記述に対応する [28]。一つの可能性は以下を仮定することである：

$$f(k) = \sqrt{\frac{|k|}{2\pi}} \, e^{i \, \text{sgn}(k) \, \phi} \tag{31}$$

ここで $\phi \in [0, 2\pi)$ は自由パラメータである。この場合、量子化EM場の上記モデルは共変的となり、場はローレンツ変換の下で期待通りに変換される [28]。因子 $\text{sgn}(k)$ は $k$ の符号を表し、式 (28) における $H_\text{eng}(t)$ が $\phi$ に依存しないことを保証するために指数に加えられている。$f(k)$ のこの選択に対するエネルギー観測量を計算すると、$a_{s\lambda}(k)$ がエネルギー $\hbar c|k|$ の単色光子の消滅演算子として解釈でき、局所的に作用する消滅演算子 $a_{s\lambda}(x, 0)$ が Titulaer と Glauber の $b$ 消滅演算子 [49] と多くの類似点を持つことが分かる。

しかし、上記の $|f(k)|$ は正の $k$ 値だけでなく負の $k$ 値に対しても非ゼロである。これは本論文で量子化EM場のヒルベルト空間を、正の $k$ のみを考慮する標準的な記述と比較して実効的に倍にしていることを意味する。このヒルベルト空間の変更はEM場の交換関係にも影響する。今度は式 (26) の最後の項が消え、

$$[\xi_{s\lambda}(x, t), \xi_{s'\lambda'}^\dagger(x', t')] = 0 \tag{32}$$

この式は、電場と磁場が至る所で独立に測定可能であることを意味する。進行波の場合、局所的な電場と磁場の振幅は本質的に同一であり——定数因子だけが異なる（式 (10) 参照）。したがって、観測量 $E(x, t)$ と $B(x, t)$ が可換であることは驚くべきではない。しかし、特定の境界条件を課した後にすべての利用可能な定在波の一部のみを量子化する著者は、通常、異なる交換関係 [1–3, 57] を得る。これはそのような記述の不完全性を示している。

シュレーディンガー描像における位置空間の量子化EM場の励起状態は、生成演算子 $a_{s\lambda}^\dagger(x, 0)$ を真空状態に作用させることで得られる。例えば、（非規格化の）状態

$$|1_{s\lambda}(x)\rangle = a_{s\lambda}^\dagger(x, 0)|0\rangle \tag{33}$$

は、位置 $x$ における単一の高度に局所化された場の励起を記述する。二つの単一励起状態間の重なりを計算すると、この重なりがそれぞれの局所消滅・生成演算子の交換関係に依存することが分かる。具体的には、近似なしに

$$\langle 1_{s\lambda}(x) | 1_{s'\lambda'}(x') \rangle = \langle 0 | [a_{s\lambda}(x, 0), a_{s'\lambda'}^\dagger(x', 0)] | 0 \rangle \tag{34}$$

式 (25) と (31) をこの式に代入すると、最終的に

$$\langle 1_{s\lambda}(x) | 1_{s'\lambda'}(x') \rangle = \frac{1}{2\pi} \delta_{s,s'} \delta_{\lambda,\lambda'} \int_{-\infty}^{\infty} dk \, |k| \, e^{isk(x - x')} \tag{35}$$

が得られる。この式は $\delta$ 関数の空間微分と関連付けることができる [58]。例えば、

$$\langle 1_{s\lambda}(x) | 1_{s\lambda}(0) \rangle = \frac{1}{2\pi} \int_{-\infty}^{\infty} dk \, |k| \, e^{iskx} = \frac{s}{\pi} \frac{d}{dx} \text{Im}\left( \int_0^\infty dk \, e^{iskx} \right) \tag{36}$$

厳密には、上式はすべての位置 $x$ に対して非ゼロであり、これは $x$ 軸に沿ったどこでも状態 $|1_{s,\lambda}(0)\rangle$ が検出される非ゼロの確率が存在することを意味する。しかし、上式はまた、$x$ が $x = 0$ に非常に近くなければこの確率は極めて小さいことを示す。すなわち、ほとんどの目的において、式 (31) のような $f(k)$ を持つ $a_{s\lambda}(x, t)$ 演算子を高度に局所化された場の励起と関連付けることは十分に正当化される。

## 3.2 真に局所的なボソン場の励起 (Truly local bosonic field excitations)

しかし、後に述べるように、局所的に作用する相互作用ハミルトニアンの構築のような特定の応用に対しては、真に局所化された場の励起のための消滅演算子を導入することが有用である。そのために、式 (19) における $f(k)$ として消滅演算子 $A_{s\lambda}(x, t)$ を以下のように定義する：

$$f(k) = \frac{1}{\sqrt{2\pi}} \, e^{i \, \text{sgn}(k) \, \phi} \tag{37}$$

この式を用いると、消滅演算子 $A_{s\lambda}(x, 0)$ がボソン交換関係に従うことが示せる：

$$[A_{s\lambda}(x, 0), A_{s'\lambda'}^\dagger(x', 0)] = \delta_{s,s'} \delta_{\lambda,\lambda'} \delta(x - x') \tag{38}$$

したがって、以下で定義される異なる単一励起状態 $|1_{s\lambda}(x)\rangle$ の重なりは

$$|1_{s\lambda}(x)\rangle = A_{s\lambda}^\dagger(x, 0)|0\rangle \tag{39}$$

単純に以下で与えられる：

$$\langle 1_{s\lambda}(x) | 1_{s'\lambda'}(x') \rangle = \delta_{s,s'} \delta_{\lambda,\lambda'} \delta(x - x') \tag{40}$$

$A_{s\lambda}(x, 0)$ 演算子の単一励起状態は対で直交しており、$A_{s\lambda}^\dagger(x, 0)$ 演算子を真空状態に適用することで生成される場の励起は真に局所化されている。

上で見たように、一般に自由空間における光の伝搬をモデル化する際に正と負の周波数光子を区別する必要はない [32–34]。しかし、ボソン交換関係を持つ局所的に作用する消滅演算子を得るためには、係数 $f(k)$ が正と負の $k$ 値の両方で非ゼロであることが必要である。標準的な量子化EM場のヒルベルト空間を拡張するために支払う代価は、電場ベクトルと磁場ベクトルのような場の観測量 $E(x, t)$ と $B(x, t)$ の表現が、$a_{s\lambda}(x, t)$ 演算子を使う場合よりも $A_{s\lambda}(x, t)$ 演算子を使う場合の方が複雑になるということであるが、不可能ではない。詳細は文献 [28] を参照。

## 3.3 量子化EM場の標準的記述への復帰 (How to return to the standard description of the quantized EM field)

通常の教科書における量子化EM場の電場・磁場観測量 $E(x) = E(x, 0)$ と $B(x) = B(x, 0)$ の表現式 [26] を回復するためには、$\phi = \pi/2$ を選び、$k < 0$ に対して $f(k) = 0$ とし、$k > 0$ に対しては式 (31) で与えられる $f(k)$ を仮定する必要がある。この場合、式 (28) のエネルギー観測量 $H_\text{eng}(t)$ は式 (23) の力学的ハミルトニアン $H_\text{dyn}$ に簡約され、$a_{s\lambda}(k, t)$ 演算子はすべて正の周波数 $\omega = ck$ と正のエネルギー $\hbar\omega$ を持つ光子を記述する。第3.1節で見たように、$a_{s\lambda}(k, t)$ はボソン交換関係に従うが、上述の $f(k)$ を用いた対応する消滅演算子 $a_{s\lambda}(x, t)$ の交換関係は非自明である。
