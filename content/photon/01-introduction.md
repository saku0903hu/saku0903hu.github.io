# 1. 序論 (Introduction)

古典電磁気学では、光をその局所的な性質——局所振幅、伝搬方向、偏光——によって特徴づけることが多い。光の基本的な運動方程式であるマクスウェル方程式は局所的な微分方程式である。実用上、古典的な電磁（EM）場は局所的な場の励起の連続体から成ると仮定する。これに対し、量子電磁気学では日常的にEM場を単色波に分解するが、これらは高度に非局所的である。このような非局所的なアプローチは、厳密には必要でないほど複雑な運動方程式をもたらしうる。例えば、巨視的量子電磁気学のグリーン関数は、観測者の位置をすべての空間位置および光子周波数と相関させる [[1](references#ref1), [2](references#ref2), [3](references#ref3)]。そこで本論文では、別のアプローチを取り、位置空間においてEM場を量子化する。古典電磁気学と同様に、我々の運動方程式は局所的な性質にのみ依存する。したがって、これらの方程式は、局所的な光と物質の相互作用を含む系や超広帯域光子波束を特徴とする系のモデル化など、多くの応用が見出されると期待される [[4](references#ref4), [5](references#ref5), [6](references#ref6), [7](references#ref7)]。

位置空間の方がより容易に解析できる状況の例として、本論文では両面半透明ミラーによる光の散乱に焦点を当てる。この話題はすでに文献で多くの関心を集めている（例えば文献 [[8](references#ref8), [9](references#ref9), [10](references#ref10), [11](references#ref11), [12](references#ref12), [13](references#ref13), [14](references#ref14), [15](references#ref15), [16](references#ref16), [17](references#ref17), [18](references#ref18), [19](references#ref19), [20](references#ref20)] 参照）。古典的なグリーン関数を用いる方法 [[1](references#ref1), [2](references#ref2), [3](references#ref3)] に加え、半透明ミラーを、EM場のヒルベルト空間をいわゆる三重項モードの部分集合に制限することで記述することもできる [[8](references#ref8)]。これらは入射波、反射波、透過波から成り、一方の側から半透明ミラーに近づく光に対してよく知られた古典的な場の期待値のダイナミクスを再現するために用いられる。しかし、この方法では、波束が両側からミラー表面に近づく状況を、非物理的な干渉効果を予測することなく記述することができない [[21](references#ref21)]。そのため、一部の著者は入力・出力形式 [[10](references#ref10), [11](references#ref11), [12](references#ref12)] や、半透明ミラーによる光散乱を類似の自由空間シナリオに対応付ける量子ミラー像検出器法 [[19](references#ref19), [20](references#ref20)] のような現象論的アプローチを好む。これらのモデルは設計対象の実験をよく記述するが、基本原理から導出されたものではない。

古典電磁気学のミラー像法は、散乱体と接触する波束を、少なくとも部分的にそのミラー像で置き換えることにより、光の散乱を単純に記述する [[22](references#ref22)]。半透明ミラーの場合、ミラー像は場の振幅が低減された波束であり、反対方向に伝搬し、反対側から出てきたように見える。本論文では類似のアプローチを取る。まず、位置空間においてEM場を量子化し、我々のアプローチがEM場の標準的な記述を含むことを示す。その後、従来の内積に関してボソン交換関係を持つ局所的に作用する場の消滅演算子を用いて、局所的に作用するミラー・ハミルトニアンを構築し、これらがよく知られた古典的なダイナミクスを再現することを示す。例えば、入射波束を出射波束に完全に変換しつつ、出射波束のダイナミクスは変えないようにすることができる。ほとんどの量子系がハミルトニアンを持つため、光学素子にも同様のことが当てはまるべきである。

自由空間における一次元のマクスウェル方程式を解く際、通常、その基本解は実数の波数 $k$ を持つ単色進行波であると仮定する。慣例として、正と負の $k$ はそれぞれ右進行波と左進行波に対応する。これらの単色波は古典EM場の完全な記述を提供する。なぜなら、それらを重ね合わせることで任意の形状の波束を生成できるからである。例えば、

$$E(x) = \frac{1}{2\pi} \int_0^\infty dk \left[ E_0 \, e^{ikx} + \text{c.c.} \right] \tag{1}$$

は、位置 $x = 0$ において高度に局所化された振幅 $E_0$ の右進行波束の電場振幅である。これが確かにそうであることを示すために、上式の第二項で $k$ を $-k$ に置換すると、

$$E(x, 0) = \frac{1}{2\pi} \int_{-\infty}^{\infty} dk \, E_0 \, e^{ikx} = E_0 \, \delta(x) \tag{2}$$

となり、$x = 0$ でのみ非ゼロとなる。次に、この高度に局所化された波束に $e^{i\pi/2} = i$ の全体位相因子を加える——すべての進行波に $\pi/2$ の位相を加える——と、上記波束の電場振幅は

$$E(x) = \frac{1}{2\pi} \int_0^\infty dk \left[ i E_0 \, e^{ikx} + \text{c.c.} \right] \tag{3}$$

となり、もはや $x = 0$ における高度に局所化された波束を記述しない。すなわち、（実数の）電場振幅は

$$E(x) = \frac{i E_0}{2\sqrt{2\pi}} \left[ \int_0^\infty dk \, e^{ikx} - \int_{-\infty}^0 dk \, e^{ikx} \right] \tag{4}$$

で与えられ、これは至る所で非ゼロである。式 (1) の第一項を消滅演算子 $a(x)$ の期待値と対応付けて位置空間でEM場を量子化したい場合、$a(x)$ に因子 $i$ を掛けると電場振幅が局所的なものから至る所で非ゼロなものに変わりうるという問題が生じる。これはあってはならない。

解決策として、以下ではマクスウェル方程式の正の周波数解と負の周波数解の**両方**をEM場の記述に含める。具体的には、マクスウェル方程式の基本解が正と負のパラメータ $k$ 、2つの異なる伝搬方向 $s = \pm 1$ 、2つの異なる偏光 $\lambda = H, V$ を持つ単色進行波であると仮定する。上と同様に、これらの単色進行波を重ね合わせることで任意の形状の波束を形成できる。例えば、

$$E(x) = \frac{1}{4\pi} \int_{-\infty}^{\infty} dk \left[ E_0 \, e^{ikx} + \text{c.c.} \right] = \frac{1}{2} [E_0 + \text{c.c.}] \, \delta(x) = \text{Re}(E_0) \, \delta(x) \tag{5}$$

は、電場振幅が $E_0$ の実部で与えられる、位置 $x = 0$ における高度に局所化された波束を記述する。しかし、この式の第一項を消滅演算子 $a(x)$ の期待値と対応付けた場合、量子場の理論で通常行われるようにこの演算子の相対位相を変えても局所性は保たれる。

上述の位相問題は、フェルミ問題 [23] の核心にもあると思われる。実際、正の周波数の光子のみの自由放射場に2つの原子を結合させると、アインシュタインの因果律の破れ——すなわち、光速を超えて一方の原子から他方にエネルギーが伝搬するという予測——が生じることが示されている [24, 25]。我々の直観では、共鳴的および非共鳴的な原子-場相互作用に起因する原子-場系のダイナミクスが、相互作用描像におけるハミルトニアンの結合定数に複素位相因子を付加し、それにより結果的に非局所的になると示唆される。

以上を踏まえ、本論文では、マクスウェル方程式の負の周波数解と正の周波数解の両方を量子化し、EM場の力学的ハミルトニアンが正と負の固有値 $\hbar\omega$ を持つと仮定する。ここで光子の周波数 $\omega$ は

$$\omega = ck \tag{6}$$

で与えられ、$c$ は光速を表す。図1に示すように、このアプローチは量子化EM場のヒルベルト空間を標準的な記述と比較して実効的に倍にする [[26](references#ref26)]。上記の定義により、以下では負と正の $k$ を持つ光子をそれぞれ負の周波数光子と正の周波数光子と呼ぶ。図1の表記を用いると、単色進行波の波数は $sk$ に等しい。しかし、後に見るように、量子化EM場のエネルギー観測量は正であり、すべての光子は正のエネルギー期待値 $\hbar c |k|$ を持つ。したがって、量子化EM場の力学的ハミルトニアンとエネルギー観測量はもはや同一ではない。

> **図1**: 本論文では、通常の量子化一次元EM場のヒルベルト空間を実効的に倍にし、その基本エネルギー量子を伝搬方向 $s = \pm 1$、偏光 $\lambda = H, V$、および正にも負にもなりうる周波数 $\omega = ck$ で同定する。すなわち、後に見るように、光のダイナミクスを生成するハミルトニアンの固有値 $\hbar\omega$ は正にも負にもなりうる。この表記では、光子の常に正のエネルギーおよび対応する古典的波数はそれぞれ $\hbar c|k|$ および $sk$ である。

後に述べるように、正と負の周波数光子の両方を考慮することにより、量子化EM場の局所的な記述を構築できる。この記述では、高度に局所化された場の励起が基本的な構成要素であると仮定する。これらは、それぞれの位置 $x$、伝搬方向 $s$、偏光 $\lambda$ によって特徴づけられる。すべての波束と同様に、伝搬方向が明確に定義された高度に局所化された場の励起は光速で伝搬し、これは直ちに運動方程式を意味する。後に、この運動方程式がシュレーディンガー方程式に帰着できることを見る。本論文では、対応する運動量表現と、両方の間の明確に定義された変換を伴う量子化EM場の位置表現を目指す [[27](references#ref27), [28](references#ref28)]。もちろん、これらの変換は可逆でなければならず、負の周波数光子の導入によりここで適用される。

多くの著者が、質量粒子の波動関数と類似した有意義な単一光子波動関数の定義を導入しようと試みてきた [[29](references#ref29), [30](references#ref30), [31](references#ref31)]。しかし、光子波動関数は質量粒子と質量のない粒子の間の多くの違いにより議論の多い概念である。例えば、このアプローチは通常、自由放射場の相対論的性格のために問題に直面する [[32](references#ref32), [33](references#ref33), [34](references#ref34), [35](references#ref35)]。もう一つの問題は、自由空間における単一光子波動関数を完全に局在化することの不可能性に由来する [[36](references#ref36), [37](references#ref37), [38](references#ref38), [39](references#ref39)]。その結果、EM場を位置空間で量子化することは不可能であると多くの人が信じており、いくつかの不可能定理が提出されてきた [[40](references#ref40), [41](references#ref41), [42](references#ref42), [43](references#ref43)]。幸い、これらの定理は克服可能な仮定に基づいている [[44](references#ref44), [45](references#ref45), [46](references#ref46)]。Hawton と Debierre [[47](references#ref47), [48](references#ref48)] と同様に、我々はマクスウェル方程式の正と負の周波数解を量子化することでこれを行う。さらに、系のハミルトニアンとエネルギー観測量が常に同一でなければならないという考えを放棄する。

ただし、高度に局所化された場の励起の消滅演算子は異なる方法で定義できる [[28](references#ref28)]。そのような消滅演算子の具体例として、Titulaer と Glauber の $b$ 演算子 [[49](references#ref49)] がある。これはいわゆるテンポラルモード [[50](references#ref50), [51](references#ref51)] の観点から量子化EM場を記述する。しかし、これらは従来の内積に関してボソン交換関係に従わず、互いに直交する状態を対で生成しない。さらに、後に見るように、ボソン交換関係を持つ局所的に作用する消滅演算子を構築することが可能である。これらは局所的に作用するミラー・ハミルトニアンの構築に用いることができる。そうすることにより、負の周波数光子を導入するさらなる理由を同定し、以下にまとめる：

**(1)** 負の周波数光子の存在なしには、ボソン交換関係を持つ真に局所化された場の励起に対する消滅演算子を定義できず、したがって局所的に作用するエルミートなミラー・ハミルトニアンを構築できない。

**(2)** 半透明ミラーによる散乱は入射光子の周波数を変えない。後に見るように、正の周波数は正のまま、負の周波数は負のままである。その結果、ユニタリなビームスプリッター変換を、正の周波数光子同士のみを結合する有効相互作用ハミルトニアンと関連付けることが可能である。しかし、負の周波数光子の部分空間を無視すると、そのような有効ハミルトニアンは入射波束**と**出射波束の両方に常に作用する。ミラーの界面に向かって進む波束と、そこから離れる波束を区別することができなくなる。

**(3)** 最後に、すでに上述したように、対応する運動量表現と両方の記述の基底状態間の明確に定義された変換を伴う量子化EM場の位置表現を目指す。詳細は文献 [[28](references#ref28)] を参照。

本論文は5つのセクションから成る。第2節では、高度に局所化された場の励起の消滅・生成演算子を用いた量子化EM場の完全な記述を提供する。これは交換関係を指定せず、力学的ハミルトニアンを同定することなく行われる。第3節では、高度に局所化された場の励起の消滅演算子とEM場の単色励起の消滅演算子との関係を研究する。さらに、量子物理学の従来の内積に関して真に局所的なボソン消滅・生成演算子を構築する。第4節では、これらの局所的ボソン演算子を用いて、両面半透明ミラーの存在下での光散乱をモデル化する局所的に作用するミラー・ハミルトニアンを導出し、例えばこれらのハミルトニアンが入射波束にのみ作用し、出射波束には作用しないことを示す。最後に、第5節で我々の結果をまとめる。
